Overview

Travel booking was fragmented, frustrating, and slow — Synopsis was the fix.

Synopsis is a unified booking platform for car rentals, hotel stays, and travel itineraries. The challenge was bringing together multiple booking flows that typically exist across separate apps and sites into a single, cohesive, delightful experience.

I designed the end-to-end UX — from initial search to post-booking itinerary — with a focus on reducing decision fatigue and cutting reservation completion time significantly.

Detail

The Problem

Travellers were switching between 4+ apps to plan a single trip — losing time and losing confidence.


  • 01

    No single source of truth

    Cars, hotels, and itineraries lived in separate apps. Users had to manually cross-reference prices, dates, and availability — increasing cognitive load.

  • 02

    Overwhelming filter systems

    Existing platforms offered 20+ filter options upfront. Users experienced choice paralysis and abandoned searches before booking.

  • 03

    Broken checkout on mobile

    Long forms, poor keyboard handling, and no progress indication made mobile checkout a consistently frustrating experience.

Process
01

Research

User surveys, journey mapping, and competitive analysis across Booking.com, Airbnb, and Rentalcars.

02

IA & Flows

Mapped the unified booking architecture and defined all user flows before moving to visual design.

03

Design

Figma wireframes through to high-fidelity. Mobile-first, then responsive web — same design system across both.

04

Usability Tests

8-participant moderated sessions. Iterated on checkout flow and filter UX based on direct feedback.

Key Solutions
  • 01

    Unified search — one query, all options

    A single search input returns cars, hotels, and packages simultaneously, with smart defaults based on destination.

  • 02

    Progressive filter disclosure

    Only 3 filters shown by default (price, rating, distance). Full filter panel accessible via "More filters" — reducing initial overwhelm.

  • 03

    3-step mobile checkout

    Reduced form fields from 14 to 7, added auto-fill support, progress indicator, and inline error validation.

  • 04

    Itinerary dashboard

    Post-booking view consolidating car, hotel, and flight details in a single timeline view — eliminating the need for a second app.

Outcomes
−60% Reduction in booking friction and completion time
67 NPS score post-launch (up from 32)
↑ Increased bookings across all traveller segments

The unified platform dramatically reduced reservation completion time and received consistent praise for its clean interface and effective search. NPS jumped from 32 to 67 post-launch, reflecting a genuine step-change in user satisfaction.
